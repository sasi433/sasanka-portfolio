# Privacy Review

This checklist must be completed before the repository or website is made public. Phase 0 contains placeholders only and no real credentials or private contact details.

## Repository

- [ ] Search tracked files and Git history for secrets, tokens, and credentials.
- [ ] Confirm `.dev.vars` and private environment files were never committed.
- [ ] Search for phone numbers, private email addresses, home addresses, and exact locations.
- [ ] Search for local paths containing personal usernames.
- [ ] Confirm no open-source licence is present.
- [ ] Confirm the README rights notice is present and accurate.

## Professional confidentiality

- [ ] Confirm no employer-owned code, screenshots, logs, documents, or diagrams are present.
- [ ] Confirm internal names, URLs, ticket identifiers, registry addresses, and customer names are absent.
- [ ] Confirm experience wording accurately distinguishes client assignments from direct employment.
- [ ] Confirm outcomes and metrics are verified and publicly shareable.

## Media and public content

- [ ] Review every image and remove unnecessary metadata.
- [ ] Confirm every external link is intentionally public.
- [ ] Confirm no family information or photographs are present.
- [ ] Confirm no public phone number, private email address, or availability status is displayed.

## Release approval

- [ ] Review every public sentence.
- [ ] Verify Cloudflare environment variables and encrypted secrets.
- [ ] Verify preview environments are not intended for indexing.
- [ ] Approve repository visibility change and production launch.
